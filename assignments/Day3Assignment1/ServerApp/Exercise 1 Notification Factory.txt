Exercise 1: Notification Factory
Scenario:
Your system sends different types of notifications: Email, SMS, Push.
Depending on user input, create the right notification class.
Tasks for Students:
•	Create an INotification interface.
•	Implement EmailNotification, SmsNotification, PushNotification.
•	Create a NotificationFactory.GetNotification(string type) method.
•	Test by asking user input and sending the notification.
Hint:
Use Simple Factory.
